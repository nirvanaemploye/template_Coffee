# BrewBeans — Modern Coffee Shop React Website

BrewBeans is a modern, fully responsive React website template perfect for coffee shops, cafes, and beverage businesses.  
It comes with 5 core pages: **Home**, **About**, **Services**, **Contact Us**, and **Order**.  
The Home page features a hero section, “How We Made Coffee,” “Favourite Coffee Flavours,” customer testimonials, and more.

---

## Features

- **React 18+** with Functional Components & Hooks
- **Vite** for lightning-fast builds
- Fully responsive layout with **Tailwind CSS**
- Clean, modern coffee-brand design
- **AOS Animation on Scroll**
- SEO-ready with semantic HTML5
- Reusable and modular components
- PNG & SVG images
- React Slick Slider integration
- Google Maps integration
- Pacifico & Sans-Serif fonts
- Easy customization

## Requirements
Before you begin, make sure you have installed:
- [Node.js](https://nodejs.org/) **v18+**
- npm, yarn, or pnpm (your choice)
- A code editor like [VS Code](https://code.visualstudio.com/)
- Git (optional, for version control)

---

## Installation
1. **Download & Extract** the ZIP file from Envato.
2. Open a terminal in the project folder.
3. Install dependencies:
   ```bash
   npm install
4. Start the development server:
    npm run dev
5. Open the URL shown in your terminal.
6. To create a production-ready build:
   npm run build

## Scripts (from package.json)
- These scripts are already included in the project. Run them using:
    npm run <script-name>

## Available Scripts:
- npm run dev → Starts the local development server using Vite.

- npm run build → Builds the project for production (optimized bundle in dist/).

- npm run preview → Previews the production build locally.

- npm run lint → Runs ESLint to check for code style & errors (optional).



## Customization
- All styles are managed via Tailwind CSS classes and config in tailwind.config.js.

- Fonts are loaded via Google Fonts in index.css.

- Images are located in the /assets folder.

- Components are inside /src/components.
